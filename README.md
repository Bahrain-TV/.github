# Repository Configuration

This directory contains the GitHub-specific configuration files for the Bahrain TV organization.

## Contents

- `workflows/` - GitHub Actions workflows
  - `jekyll-gh-pages.yml` - Automated Jekyll build and deployment to GitHub Pages

## Setup

These configurations enable:

1. **Automatic Deployment**: Pushes to `main` branch automatically build and deploy the Jekyll site
2. **GitHub Pages Hosting**: Static site hosting with custom domain support
3. **Build Optimization**: Pre-installed Jekyll dependencies for faster builds

## Website Repository

The main website code is in the parent directory and uses:

- **Jekyll**: Static site generator
- **SCSS**: CSS preprocessing
- **Modern JavaScript**: Vanilla JS with progressive enhancement
- **Responsive Design**: Mobile-first approach
- **Accessibility**: WCAG 2.1 compliance
